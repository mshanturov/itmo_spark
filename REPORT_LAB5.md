# Отчёт по лабораторной работе №5

**Дисциплина:** Инфраструктура больших данных  
**Тема:** Модель кластеризации на PySpark

## 1. Цель работы

Получить навыки настройки Spark-окружения, проверки работоспособности Spark-компонентов
и разработки модели кластеризации (KMeans) на PySpark.

## 2. Что реализовано

1. Подготовлена среда для Spark-вычислений (Python + PySpark + Java).
2. Проверена работоспособность Spark на задаче WordCount.
3. Реализована загрузка и сэмплирование данных OpenFoodFacts.
4. Реализована предобработка данных и формирование числовых фичей.
5. Реализован подбор количества кластеров и обучение KMeans по silhouette-метрике.
6. Сохранены результаты кластеризации и метрики в файлы.

## 3. Закрытие замечаний по ЛР5

- ✅ **Декомпозиция по файлам:** общие части вынесены в `src/settings.py`, `src/spark_session_factory.py`, `src/openfoodfacts_features.py`.

## 4. Использованные признаки и обоснование

Использованы признаки на 100 г продукта:
- `energy_kcal_100g`
- `fat_100g`
- `carbohydrates_100g`
- `sugars_100g`
- `proteins_100g`
- `salt_100g`

Обоснование:
1. Признаки количественные и подходят для KMeans после стандартизации.
2. Они отражают базовый нутриентный профиль продукта.
3. По этим показателям естественно разделяются группы (более сладкие/солёные/белковые/жирные и т.д.).

## 5. Результаты запуска

Фактические результаты:
- загружено строк: **50 000**;
- после предобработки: **27 702**;
- протестированы `K = 2..6`;
- лучший результат: **K = 4**, `silhouette = 0.6191`.

Сформированы артефакты:
- `data/processed/openfoodfacts_features.parquet`
- `data/output/openfoodfacts_clusters.parquet`
