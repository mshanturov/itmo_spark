# Отчёт по лабораторной работе №5

**Дисциплина:** Инфраструктура больших данных  
**Тема:** Модель кластеризации на PySpark

## 1. Цель работы

Получить навыки настройки Spark окружения, проверки его работоспособности и разработки
PySpark-приложения с кластеризацией KMeans.

## 2. Выполненные шаги

1. Подготовлена среда для Spark вычислений (Python + PySpark + Java).
2. Проверена работа Spark компонентов на примере `WordCount` (`src/wordcount.py`).
3. Реализована загрузка и сэмплирование OpenFoodFacts (`src/download_openfoodfacts_sample.py`).
4. Выполнена предобработка данных:
   - выделены числовые признаки пищевой ценности,
   - удалены пропуски,
   - применены ограничения диапазонов для адекватной выборки.
5. Реализована кластеризация KMeans на PySpark (`src/kmeans_clustering.py`):
   - масштабирование признаков,
   - тестирование нескольких K,
   - выбор лучшего K по silhouette.
6. Сформированы артефакты:
   - `cluster_metrics.json`,
   - `cluster_centers.json`,
   - `openfoodfacts_clusters.parquet`.

## 3. Использованные признаки

Для кластеризации использованы признаки (на 100 г продукта):
- `energy_kcal_100g`
- `fat_100g`
- `carbohydrates_100g`
- `sugars_100g`
- `proteins_100g`
- `salt_100g`

## 4. Результаты

В результате получено рабочее Spark приложение:
- подтверждена работоспособность Spark платформы (WordCount);
- реализована модель кластеризации KMeans на PySpark;
- подготовлен дистрибутив `dist/lab5_distribution.zip`.

Фактические результаты запуска:
- размер загруженного сэмпла: **30 000** строк;
- размер выборки после предобработки: **16 383** строки;
- протестированные значения K: `2, 3, 4, 5, 6`;
- лучший результат: **K = 6**, `silhouette = 0.6263`.
